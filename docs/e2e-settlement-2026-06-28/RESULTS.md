# deetz 정산 시스템 — 3자 관점 E2E 결과 (2026-06-28)

> Claude Chrome 실제 브라우저 + DB 검증으로 전 구간 통과.
> 시나리오: **테스트엔터테인먼트가 테스트안무가에게 100만원 수주 → 댄서 A·B·C에게 각 10만/10만/30만 지급(마진 50만)**

## 등장 (테스트 계정, 검증 후 정리됨)
| 역할 | 계정 |
|---|---|
| 안무가(소유자) | choreo.e2e@deetz.test (테스트안무가) |
| 댄서 A/B/C | dancera/b/c.e2e@deetz.test |
| 관리자(경영지원실=실제 이체) | admin.e2e@deetz.test |
| 프로젝트 | [E2E] 테스트엔터 안무 정산 (비공개) |

## ① 안무가 관점 — 수집·배분·마진
1. `/projects/<id>/settlements` 콘솔 진입
2. **클라이언트 수주액 1,000,000원** 입력 → 예상 마진 자동계산
3. **정산 수집 링크 발급** → `deetz.kr/settle/iMbJXkK` (구글폼 대체)
4. 댄서 제출 후 댄서별 배분 입력: **A 100,000 / B 100,000 / C 300,000**
5. 결과: 댄서 배분 합계 −500,000 / **예상 마진 500,000원**

## ② 댄서 관점 — 셀프 지급정보 제출 (로그인 필수)
A·B·C가 각각 `/settle/iMbJXkK`에서 로그인 후 제출 (금액칸 없음 = 안무가가 정함):

| 댄서 | 은행 | 계좌 | 주민번호 | 결과 |
|---|---|---|---|---|
| A | 카카오뱅크 | 1111111111111 | 입력 | 제출 완료 ✓ |
| B | (하나은행) | 2222222222222 | 입력 | 제출 완료 ✓ |
| C | (하나은행) | 3333333333333 | 입력 | 제출 완료 ✓ |

- DB: 3건 모두 `origin=self_collected`, `gross_amount=null`(=금액 미정), 계좌·주민번호 `dancer_private_info`(RLS 분리)에 저장. 계좌 하이픈 자동 제거.
- 금액 확정 후 댄서 `/me/정산·출금`: **입금완료 · 96,700원 입금 완료 · 2026.06.28** 표시(A 기준).

## ③ 관리자 관점 — 실제 이체 실행 (경영지원실)
`/admin/settlements` 코크핏:
1. 3건이 "정산완료·출금신청 전"에 표시 (✓계좌 ✓주민번호)
2. 3건 선택 → **다계좌이체 파일** 생성 → `deetz_다계좌이체_20260628_1401.xls` 다운로드
   - 파일 내용(우리은행 6열 양식, 헤더 없음):
     ```
     카카오뱅크  1111111111111  96700   [E2E]테스트테스트댄서A
     하나은행    2222222222222  96700   [E2E]테스트테스트댄서B
     하나은행    3333333333333  290100  [E2E]테스트테스트댄서C
     ```
   - **이체금액 = 실수령액**(세전 − 3.3% 원천징수): 100,000→96,700 / 300,000→290,100 ✓
3. **일괄 입금완료** → 3건 `status=paid`, `paid_at=2026-06-28 14:09 KST`
4. 댄서 화면이 자동으로 "입금완료"로 전환

## 검증 요약
- 세금 계산: 3.3% 원천징수 정확 (100,000→실수령 96,700, 300,000→290,100)
- 마진: 수주 1,000,000 − 배분 500,000 − 실비 0 = **500,000** ✓
- 멱등성: 댄서 재제출해도 1행 유지·소유자 금액 보존(별도 검증)
- 멀티테넌트: 안무가는 본인 프로젝트만(canManageProject), 실지급은 관리자(경영지원실)
- 구글폼 대비: 주민번호 평문 시트 → RLS 분리 / 수기 입금 → 다계좌이체 파일+원천징수 자동

> 비고: B·C 은행이 "하나은행"으로 표기된 건 테스트 중 은행 선택 UI 자동화 한계일 뿐, 정산·이체 로직과 무관(계좌·예금주·주민번호·금액 모두 정확).
> 스크린샷: 작업 대화 트랜스크립트 인라인 이미지 참조(안무가 콘솔/댄서 제출/관리자 코크핏/댄서 입금완료).
