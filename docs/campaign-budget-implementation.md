## 예산 화면

`/tools/campaigns/[projectId]?tab=budget`에서 운영 예산·필요 예상액·잔액·합의 출연료·정산 등록액·운영비 확보액을 확인한다.
총예산·운영비·정산 등록액은 기존 재무 정책에 따라 슈퍼관리자 전용이며, 서버 조회·액션·SQL에서 확인한다.
일반 관리자와 해당 공동관리자는 제출 현황·수기 참여자·참여자별 출연료를 관리한다.
공동관리자 응답에는 총예산·운영비·정산 등록액을 조회하거나 포함하지 않는다.
운영 링크 복사로 기존 관리자들이 같은 현황을 열 수 있으며, 자동 알림이나 외부 발송은 하지 않는다.
비로그인·참여자·공개 캐스팅 보드·성과 보고서에 신규 예산 데이터가 포함되지 않는다.

참여자별 금액은 협의 예상과 합의 완료를 구분하고, 확인 근거를 필수로 받는다.
0원은 무료 합의로 구분하며 빈 금액은 미확인이다.
수정 전 값과 처리자·시각은 `campaign_budget_events`에 남긴다.
지급·정산·매출 원장은 변경하지 않는다.

필요 예상액은 참여자별 계획 금액과 해당 댄서의 출연료 정산 등록액 중 큰 값을 사용한다.
여기에 기타 정산과 운영비 확보액을 더한다.
운영비 확보액은 별도 예약액과 등록 실비 중 큰 값이다.
정산의 부가세 금액은 등록액에 포함하며 취소 정산은 제외한다.
희망 단가와 예상액을 자동으로 더하지 않고, 계획과 정산이 같은 출연료를 가리킬 때도 중복으로 더하지 않는다.
미확인 출연료·운영비·금액 없는 정산이 있으면 잔액은 확인된 금액만 차감한 참고값임을 표시한다.
정산 상태만으로 지급 완료를 판단하지 않으며 기존 정산·지급 화면을 연결한다.

## 별도 연락한 참여자

제출 현황의 `참여자 수기 추가`에서 활동명·Instagram 계정·담당자·연락 확인 근거를 입력한다.
가입 회원의 프로필, 회원 계정이 없는 프로필, 프로필 없는 참여자를 모두 지원한다.
활동명으로 기존 프로필을 검색해 계정을 대조하며 계정이나 프로필을 자동 생성하지 않는다.
나중에 참여자 상세의 `수기 참여자 정보·프로필 연결 수정`에서 프로필을 연결해도 참여자 ID·출연료·제출 이력이 유지된다.
회원 계정과 연결되면 해당 회원이 본인 제출 화면을 사용할 수 있다.
관리자는 프로필 유무와 관계없이 링크 추가·수정·검토와 출연료 입력을 처리한다.

같은 캠페인의 프로필·Instagram 중복과 다른 프로젝트 접근을 차단한다.
재시도 요청은 중복 등록하지 않고, 동시 수정은 버전 충돌로 보호한다.
수기 참여자는 기본적으로 클라이언트 비공개다.
개별 공개를 선택한 참여자만 공개 설정이 켜진 보드와 발행 보고서에 반영되며 미검토 링크는 계속 제외한다.
마이그레이션은 `db/migrations/20260907151937_campaign_manual_participants.sql`이다.
