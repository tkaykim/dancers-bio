## 예산 화면

`/tools/campaigns/[projectId]?tab=budget`에서 운영 예산·필요 예상액·잔액·합의 출연료·정산 등록액·운영비 확보액을 확인한다.
예산은 기존 재무 정책에 따라 슈퍼관리자 전용이며, 서버 조회·액션·SQL에서 모두 확인한다.
일반 관리자와 공동관리자에게는 제출 현황과 운영 링크 복사만 제공한다.
비로그인·참여자·공개 캐스팅 보드·성과 보고서에 신규 예산 데이터가 포함되지 않는다.

참여자별 금액은 협의 예상과 합의 완료를 구분하고, 확인 근거를 필수로 받는다.
0원은 무료 합의로 구분하며 빈 금액은 미확인이다.
수정 전 값과 처리자·시각은 `campaign_budget_events`에 남긴다.
지급·정산·매출 원장은 변경하지 않는다.

필요 예상액은 참여자별 계획 금액과 해당 댄서의 출연료 정산 등록액 중 큰 값을 사용한다.
여기에 기타 정산과 운영비 확보액을 더한다.
운영비 확보액은 별도 예약액과 등록 실비 중 큰 값이다.
정산의 부가세 금액은 등록액에 포함하며 취소 정산은 제외한다.
희망 단가와 예상액을 자동으로 더하지 않고, 계획과 정산이 같은 출연료를 가리킬 때도 중복으로 더하지 않는다.
미확인 출연료·운영비·금액 없는 정산이 있으면 잔액은 확인된 금액만 차감한 참고값임을 표시한다.
정산 상태만으로 지급 완료를 판단하지 않으며 기존 정산·지급 화면을 연결한다.
